# 🗂️ Project Management Application (MERN Stack)

A full-stack Project / Task Management Application built using the MERN stack with Redux Toolkit for state management.
The application allows users to create, view, update, and delete tasks with a clean UI and RESTful backend.

## 🚀 Features

- Create new tasks with title and description

- View all tasks in a tabular format

- Update existing tasks using a modal

- Delete tasks

- Real-time UI updates using Redux Toolkit

- RESTful API built with Express & MongoDB

- Cross-origin support using CORS

##🛠️ Tech Stack
### Frontend

- React

- Redux Toolkit

- React Bootstrap

- JavaScript (ES6+)

### Backend

- Node.js

- Express.js

- MongoDB

- Mongoose

- dotenv

- CORS
